# 📄 KFS-2

## 🇬🇧 English

The goal of this project is to extend the kernel with more advanced operating system features.

### Description

KFS-2 continues kernel development by implementing advanced memory and process management mechanisms.

This project helps you better understand:

- multitasking
- virtual memory
- interrupt handling
- kernel architecture

### How it works

- Extends KFS-1
- Improves memory management
- Introduces process scheduling
- Enhances system stability

### Compilation

```bash
make
```

### Skills Developed

- advanced C programming
- operating systems
- process scheduling
- memory management
- low-level debugging
- kernel development
